Privacy Policy — MrSae Poster

Last updated: 17 November 2026 · MrSae Poster home

1. Who uses this app

MrSae Poster is a private tool used only by the owner of the YouTube channels มิสเตอร์แซะ (MrSae), ตีสามเล่าผี, รู้ทันมิจจี้, ใครเคยเป็นบ้าง? and ชีวิตอัปเกรด, to manage those channels. It is not offered to the public and does not collect data from viewers or other people.

แอปนี้เจ้าของช่องใช้จัดการช่องของตัวเองเท่านั้น ไม่ได้เปิดให้คนอื่นใช้ และไม่เก็บข้อมูลของผู้ชมหรือบุคคลอื่น

2. Google user data the app accesses

  • YouTube upload (youtube.upload): to upload the owner's own videos, schedule them and set their thumbnails.
  • YouTube read-only (youtube.readonly): to confirm which channel is connected and read the status and public statistics of the owner's own videos.
  • YouTube Analytics read-only (yt-analytics.readonly): to read view and retention reports of the owner's own channels.

3. How the data is used and stored

  • Access tokens are stored only on the owner's own computer and are used only for the purposes above.
  • No Google user data is sold, shared with or transferred to any third party, and it is not used for advertising.
  • No data is stored on any server operated by this app; there is none.

โทเค็นเก็บไว้ในคอมพิวเตอร์ของเจ้าของเท่านั้น ใช้ตามข้อ 2 เท่านั้น ไม่ขาย ไม่แชร์ ไม่ส่งต่อให้บุคคลที่สาม และไม่มีเซิร์ฟเวอร์เก็บข้อมูล

4. Google API Services User Data Policy

MrSae Poster's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

5. Removing access

Access can be revoked at any time at Google Account → Third-party connections. Deleting the token files on the owner's computer removes all stored access.

6. Contact

Questions about this policy: contact the channel owner through the มิสเตอร์แซะ YouTube channel.
